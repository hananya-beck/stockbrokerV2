<story_loop>
Repeat for each story in order.

1. Check the tree is clean. Read the story text from `epics.md`.
2. Launch a fresh story session in the background (see the launch command below). Write its output to the run folder.
3. Wait for it to exit (see waiting below).
4. Gate. All of these must pass:
   - `npm run check` is green.
   - `python -m pytest tests -q` is green.
   - `_bmad-output/implementation-artifacts/sprint-status.yaml` shows the story key as `done`.
   - `git status --short` is empty and `git log -1` is the story commit.
   - The session did not touch files outside its story's scope. Check with `git show --stat HEAD`.
5. If the gate fails, resume that session once with the failing output: `claude -p "<the failing command and its output, and: fix it and commit>" --resume <session_id> ...` (same flags as the launch). Run the gate again.
6. If the gate fails a second time, stop and ask.

Story session launch (run in the background, one at a time):

```
claude -p "<story prompt>" --model claude-sonnet-5-5 --permission-mode acceptEdits --allowedTools "Bash,Read,Edit,Write,Glob,Grep,Skill,Agent" --output-format json > "<run folder>\story-1-N.json" 2>&1 &
```

The story prompt must contain: the story number and title, the path to its acceptance criteria in `epics.md`, the epic context path, the done spec path, the deferred items it covers, the git rules above, and this sentence: "Run the bmad-build-auto workflow for this story. Do not create branches, do not push. When the gates pass, commit with the subject given above, mark the story done in sprint-status.yaml, then halt with the final status. If you need an answer the epic context does not give, halt blocked with the question. Do not guess."

The session's `session_id` is in its JSON output. Record it for every session.

Waiting. A foreground Bash call stops after 10 minutes, and a story can run longer. Wait in chunks, for example `timeout 540 bash -c 'while kill -0 <pid> 2>/dev/null; do sleep 20; done'`, and repeat until the process has exited. Get the pid from `$!` when you launch it. Do not poll the output file in a loop.
</story_loop>
